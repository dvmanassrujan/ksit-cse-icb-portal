# KSIT CSE (ICB) Integrated Academic & Information Portal

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/dvmanassrujan/ksit-cse-icb-portal)

A comprehensive, role-based academic portal designed and built for the **Department of Computer Science and Engineering (IoT, Cyber Security & Blockchain)** at **K. S. Institute of Technology (KSIT), Bengaluru**.

---

## 🌟 Key Features

- **Role-Based Portals**:
  - **Student Portal**: Attendance tracking, marks & SGPA calculator, assignment submissions, class timetable, and curriculum access.
  - **Faculty Portal**: Attendance marking, IA marks entry, study material uploads, assignment grading, and student performance analytics.
  - **HOD / Department Portal**: Department statistics, faculty load, timetable management, notice announcements, survey analytics, and placement logs.
- **Dual Database Engine Architecture**:
  - High-performance MySQL relational schema (`database/schema.sql` & `database/seed.sql`).
  - Seamless zero-configuration fallback to an integrated Relational Store (`database/seed.json` & `database/data_store.json`) when hosted without an external database.
- **Responsive UI/UX**: Designed with modern KSIT maroon and navy branding, fluid cards, real-time filters, and interactive charts.

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/dvmanassrujan/ksit-cse-icb-portal.git
cd ksit-cse-icb-portal

# Install dependencies
npm install

# Start the server
npm start
```
Visit `http://localhost:3000` in your web browser.
